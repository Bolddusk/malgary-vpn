# ADR-0000: Record architecture decisions

**Status**: Accepted · **Date**: 2026-11-03

## Context

Malgary VPN is built through Spec Kit. Specs, plans and tasks explain *what* each feature does.
Some decisions outlive a single feature and must be easy to find later.

## Decision

Record each such decision as an ADR in `docs/decisions/NNNN-title.md` with Status, Date,
Context, Decision and Consequences. Link the ADR from the spec or plan that produced it. An ADR
that conflicts with the constitution is invalid until the constitution is amended.

## Consequences

Decisions have a durable home next to the code. Superseded ADRs stay in place, marked
`Superseded by ADR-NNNN`.
