# Cell inventories

One YAML file per cell, generated by `infra/tools/cell-inventory.sh <env>` after `tofu apply`.
malgaryd loads them at start-up (`MALGARY_CELL_INVENTORY`) to know each cell's control hosts
and gateway pairs. The PTA registration date of each pair is recorded separately with
`malgaryctl gateway mark-pta-registered` (FR-011).
