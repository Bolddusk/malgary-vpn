# Setup page

The per-tenant onboarding page (FR-019, FR-020). The template lives in
`infra/ansible/roles/tenant-stack/templates/setup-page.html.j2` and is rendered for every tenant
to `https://<tenant>.vpn.malgary.com/setup` by the tenant-stack role. Edit it there.
Screenshots for iOS/Android steps are added after pilot test P-4 (T103).
